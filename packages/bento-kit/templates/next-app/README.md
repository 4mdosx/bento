# Bento App

Next.js App Router project initialized with Bento Kit. Hosts, request coordination and overlay runtime come from `bento-kit`; editable views live in `components/bento`.

```bash
npm run dev
```

默认 http://localhost:6000。

Replace the sample List Model and Actions in `app/page.tsx` with your resource. Add more views with `npx bento add <name>`.
