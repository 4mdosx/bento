# bento-kit

Preview package for Bento's CLI, versioned Host, Core, Integration and UI Runtime APIs. Editable Views are delivered with `npx bento init` and `npx bento add`.

Requires Node.js 24, React 19 and Next.js 16 App Router. Preview releases may change API between minor versions.

```bash
npx bento-kit@0.1.0-preview.1 init my-app
cd my-app
npm run dev
```
