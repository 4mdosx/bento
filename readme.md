# 🍱 Bento

- 快速启动项目, 专注核心业务逻辑
- 由 shadcn 和 tailwind 构建，源码级交付，UI 完全可控
- 开箱即用、内置文档

## 开发

启动 playground（组件展示与用例闭环）：

```bash
npm run dev -w playground
```

## 📁 仓库结构

```
bento/
├── README.md           # 使用说明、命令手册、升级流程
├── package.json        # 提供 npx 脚手架命令
├── cli/                # 提供 npx 脚手架命令（Node）
├── templates/          # 可选初始化模板
```
